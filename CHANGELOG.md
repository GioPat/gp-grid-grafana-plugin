# Changelog

## 1.0.0 (2026-11-07)

Initial release.

- Virtualized data grid panel built on gp-grid, reading data frames without copying rows
- Column sorting and filters, with date and time filters for time columns and date units
- Grafana standard options: unit, decimals, display name, no value and value mappings
- Per-column width, pinning and hiding through field overrides
